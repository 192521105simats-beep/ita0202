Question 1: Interpret the XML Structure 5 Marks

a. Identify the root element.
<courses>

The root element is <courses>, which wraps all individual <course> elements.

b. Identify the repeating record element.
<course>

The repeating element is <course>, each representing an individual academic course entity.

c. Identify the attribute used to uniquely identify each course.
id

The id attribute (e.g., id="C101", id="C102", etc.) on the <course> element.

d. Identify the elements that represent numeric information.
<students> <credits>

<students> represents enrolled headcount and <credits> represents course credit weightage.

e. State whether the XML document is structurally well-formed and justify your answer.
Decision: YES, the XML document is structurally well-formed.
  • Valid Declaration: Begins with standard XML declaration <?xml version="1.0" encoding="UTF-8"?>.
  • Single Root Element: Enclosed entirely within a single enclosing root tag <courses>.
  • Proper Nesting & Closure: All elements are correctly nested and closed (no mismatched or overlapping tags).
  • Valid Attributes: Attribute values are enclosed in quotes (e.g., id="C101").
  • Case Consistency: Tag names strictly follow consistent case sensitivity.
