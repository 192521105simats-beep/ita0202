About XHTML

XHTML stands for Extensible HyperText Markup Language. It is a stricter version of HTML that follows XML rules.


Features of XHTML

  • All tags are written in lowercase.
  • Every tag is properly closed.
  • Attributes are enclosed in double quotes.
  • Elements are properly nested.
  • Empty tags are self-closing.

Examples

Water Formula : H2O

Mathematical Formula : (a + b)2 = a2 + 2ab + b2
